// PIT STOP

Questions from teachers & IT

Windows says “Windows protected your PC”. Is it safe? ＋

Yes. The installer isn't code-signed yet, so Microsoft SmartScreen shows this warning for it, as it does for any new unsigned app. Click More info → Run anyway. If your school blocks unsigned software, use the browser version instead.

Can IT install it silently across a computer lab? ＋

Yes. The installer supports silent installs:

CarTyper-setup.exe /S              # current user, no admin
CarTyper-setup.exe /S /allusers    # every account on the PC (admin)

Push it with Intune, a GPO startup script, PDQ Deploy, or anything that can run an .exe. There's no MSI package at the moment.

Does it need admin rights? ＋

No. By default it installs for the current Windows user, inside their own profile. Installing for all users on a PC needs admin. The browser version needs nothing installed at all.

Where is student data stored, and how do we move it? ＋

Windows app: in a local database in each Windows user's profile (%APPDATA%\CarTyper\db).

Browser: in that browser's storage on that device. Clearing browsing data erases it.

To move or back up everything, use Backup → Export in the app. It saves one .cartyper.json file with accounts, garage, analytics, certificates, and leaderboards. Import it on the other machine.

Does it need the internet? ＋

No. The Windows app works fully offline from the moment it's installed. The browser version needs a connection to open the page — student progress is saved on that device.

Does it work on Macs, Chromebooks, or tablets? ＋

Yes — use the browser version. It's the complete game. You'll need a physical keyboard; on a tablet, connect one.

Is it really free? ＋

Yes. No in-app purchases, no premium tier. Coins are earned only by racing and spent only on cosmetics.

Something else? Ask on GitHub.
